# WP07：CLI 主题配置输入、详情输出与帮助

状态：待实施。主责：CLI。前置：主仓 WP01 契约冻结、WP05 主题 External 配置一致性。

## 修改范围与任务

- 保留现有 theme create/update 的 payload-file 机制，不为每个图片/字体字段追加一组专用命令；文档与帮助说明完整设计字段。
- `theme get` 普通输出补默认/反色 Logo、项目图标、三槽字体的来源、族 ID/名称、预设及空值；列表保持简洁。
- JSON/raw 保持已有主题投影兼容，创建/更新结果选择一致输出策略，不遗漏后续操作需要的真实 ID。
- 将省略与显式 null 原样传输；说明图片清空、字体来源互斥与恢复默认，禁止客户端自动补全旧对象或用字体文件/注册项 ID 代替 family_id。
- 命令帮助从当前 Backend OpenAPI 派生，示例以共享真值表为准；主题 key 仍不可通过 update 修改。
- 明确图片/字体属于工作空间共享主题，配置变更影响使用该主题的新预览/构建；不自动重写页面源码或切换项目主题。

## 验收标准

- [ ] 创建主题可通过 payload 传图片/字体字段，普通详情与 JSON 能确认实际绑定。
- [ ] 省略/null/恢复默认/来源切换在 HTTP 请求中无损，非法载荷遵循 Backend 错误语义。
- [ ] 同键重试保持载荷与基线，异载荷冲突不会被 CLI 隐藏或自动换键重试。
- [ ] 现有名称/说明/色板、默认创建、复制、归档与 JSON/raw 行为回归通过。
- [ ] 真实 OpenAPI 的字段和样例与帮助一致，旧 Backend 不支持字段时不走内部 API 兜底。
